About us!

EchoGrid is a studio created with the purpose to create amazing games with a community first approach. All EchoGrid games can be sorted into two files; projects and games. Our aim is to create the best games posible and with that in mind we know that we will have to try new things. Every so often we will release a "project" which is a short game made specifically to test out new features or mechanics. With every game we try to release a few projects to ensure that our features and mechanics are both polished and well recived by the community. If you have any feature requests for us to try out please feel free to contact us, we try to respond to every email and DM.
